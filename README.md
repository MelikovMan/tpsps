Для запуска приложения необходимо:
1. Наличие интернет-соединения;
2. Docker. Docker Desktop для Windows, или простая версия из управляющего пакета для Linux/Mac. Для запуска приложения из главной директории выполнить команду в командной строке: ```docker compose --profile indexer up -d```  для первого запуска для индексации Typesense

Приложение доступно на localhost:80 (убедитесь, что нет конфликтов с другими приложениями)
В дальнейшем запускать через ```docker compose up -d```

Потенциальные проблемы:
1. На Windows убедиться, что скрипт запуска /wiki-backend/scripts/start.sh в формате utf-8 с LF
2. Использовать VPN в случае неожиданных блокировок
