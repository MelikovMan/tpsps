Для запуска приложения необходимо:
1. Наличие интернет-соединения;
2. Docker. Docker Engine для Windows, или простая версия из управляющего пакета для Linux/Mac. Для запуска приложения из главной директории выполнить команду в командной строке: __docker compose --profile indexer up -d__  для первого запуска для индексации Typesense
Приложение доступно на localhost:80 (убедитесь, что нет пересечений)
В дальнейшем запускать через __docker compose up -d__
Ошибки:
1. На Windows убедиться, что скрипт запуска /wiki-backend/scripts/start.sh в формате utf-8 с LF
2. Использовать VPN в случае неожиданных блокировок
